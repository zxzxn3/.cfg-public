# Frieren Plymouth assets

This is the exact Frieren v29 theme validated by reboot on the original
CachyOS machine. The animation uses 28 unique frames and a 11,910 ms timeline.
The logical 110 × 110 artwork is also supplied at 800, 1080, 1600 and 2160 pixels
using nearest-neighbor scaling. The script chooses a matching size where
available and fits the square portrait to each display without cropping.

`theme/` is the complete install payload; `SHA256SUMS` verifies it.
Install using `../../../setup/60-frieren-plymouth.sh` from this directory,
or `setup/60-frieren-plymouth.sh` from the bootstrap root.

The character is Frieren from Frieren: Beyond Journey's End. These personal
fan-art assets do not imply ownership of the underlying character.
